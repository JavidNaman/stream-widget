## راه‌اندازی در OBS

**۱.** در پنل **Sources** روی **+** بزنید و **Browser** را انتخاب کنید.

**۲.** در کادر **URL** این آدرس را بگذارید:

```
https://JavidNaman.github.io/stream-widget/
```

**۳.** عرض و ارتفاع را این‌طور تنظیم کنید:

| | |
| --- | --- |
| **Width** | `480` |
| **Height** | `120` |

**۴.** تیک **Shutdown source when not visible** را بزنید تا وقتی صحنه فعال نیست چیزی مصرف نشود.

**۵.** **OK** بزنید و ویجت را هرجای تصویر که خواستید بگذارید.

پس‌زمینه‌ی ویجت شفاف است و روی هر صحنه‌ای می‌نشیند. کارت به **گوشه‌ی بالا-راستِ** کادر می‌چسبد و به‌اندازه‌ی اسم هر نفر باز و بسته می‌شود، پس عرض کادر را کم‌تر از ۴۸۰ نگذارید.

بین دو نفر، مشخصات از حالت واضح به تار محو می‌شوند، قاب شیشه‌ای به عرض نفر بعدی می‌رسد و بعد مشخصات تازه واضح می‌شوند. خودِ قاب هیچ‌وقت از صفحه نمی‌رود.

## تنظیمات

اگر پیش‌فرض‌ها را دوست نداشتید، این آدرس همه‌ی تنظیمات را با مقدار پیش‌فرضشان دارد. کپی کنید و هر عددی را خواستید عوض کنید:

```
https://JavidNaman.github.io/stream-widget/?duration=6000&fade=520&scale=1&glass=0.62&order=random
```

| تنظیم | پیش‌فرض | چه‌کار می‌کند |
| --- | --- | --- |
| `duration` | `6000` | هر نفر چند میلی‌ثانیه روی صفحه بماند. `6000` یعنی ۶ ثانیه. |
| `fade` | `520` | محو شدن مشخصات چند میلی‌ثانیه طول بکشد. عدد بزرگ‌تر یعنی انتقال آرام‌تر. |
| `scale` | `1` | بزرگ‌نمایی کل ویجت. `1.25` یعنی ۲۵٪ بزرگ‌تر، `0.8` یعنی ۲۰٪ کوچک‌تر. |
| `glass` | `0.62` | غلظت شیشه. عدد کم‌تر یعنی شیشه‌ی شفاف‌تر و دیده شدن بیشترِ تصویر پشتش. |
| `order` | `random` | ترتیب نمایش. با `list` فهرست به‌ترتیب اصلی جلو می‌رود. |

چند نکته:

- **`scale` را که عوض کردید**، عرض و ارتفاع Browser Source را هم به همان نسبت زیاد کنید. مثلاً با `scale=1.25` کادر را `600 × 150` بگذارید.
- **`glass` را کِی کم کنیم؟** پیش‌فرض `0.62` طوری انتخاب شده که متن حتی روی یک صحنه‌ی کاملاً سفید هم خوانا بماند. اگر صحنه‌ی شما همیشه تاریک است، `0.45` شیشه را شفاف‌تر می‌کند و قشنگ‌تر در می‌آید.
- تنظیمات را با `&` به هم وصل کنید و فقط همان‌هایی را بنویسید که می‌خواهید عوض کنید.

مثال — ۱۰ ثانیه‌ای، کمی بزرگ‌تر، با شیشه‌ی شفاف‌تر:

```
https://JavidNaman.github.io/stream-widget/?duration=10000&scale=1.25&glass=0.45
```

## داده‌ها

فهرست از [یادمان جاویدنامان ایران‌اینترنشنال](https://javidnaman.iranintl.com/memorial) گرفته شده و در [`data.json`](data.json) نگهداری می‌شود. هر نفر یک خط است:

```json
{"id":"...","name":"نام کامل","age":28,"place":"تهران","date":"۱۹ دی ۱۴۰۴","photo":true}
```

| فیلد | توضیح |
| --- | --- |
| `id` | شناسه‌ی هر نفر، که نام فایل عکسش در `images/` هم هست |
| `name` | نام کامل |
| `age` | سن، یا `null` اگر معلوم نیست |
| `place` | شهر یا محل، یا `null` |
| `date` | تاریخ شمسی، یا `null` |
| `photo` | اگر `false` باشد، کارت بدون عکس و جمع‌تر نمایش داده می‌شود |

هر فیلدی که `null` باشد، آن خط از کارت حذف می‌شود و بقیه‌ی کارت به‌هم نمی‌ریزد.

از این ۳۱۷۵ نفر، ۲۹۶۰ نفر عکس دارند، ۲۵۰۵ نفر سن، ۳۱۵۳ نفر محل و ۲۹۱۴ نفر تاریخ.

## مشارکت

اگر اسمی جا افتاده یا اطلاعاتی اشتباه است، Issue باز کنید یا مستقیم Pull Request بفرستید.

**برای اصلاح یک نفر:** فایل [`data.json`](data.json) را باز کنید، خط آن شخص را پیدا و ویرایش کنید. هر نفر یک خط جداست تا تغییرات به‌سادگی قابل بررسی باشد.

**برای اضافه کردن یک نفر:** یک خط تازه با همان ساختار بالا بنویسید. اگر عکس دارید، آن را با نام `<id>.jpg` در پوشه‌ی `images/` بگذارید و `photo` را `true` کنید؛ اگر ندارید `photo` را `false` بگذارید.

## ساختار پروژه

```
index.html    ویجت — یک فایل، بدون build و بدون وابستگی خارجی
data.json     فهرست ۳۱۷۵ نفره
images/       عکس‌ها
assets/       فونت وزیرمتن
```

ویجت به هیچ CDN، کتابخانه یا سرویس بیرونی وصل نمی‌شود؛ هرچه لازم دارد داخل همین مخزن است.
