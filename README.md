## OBS

**Sources** ← **+** ← **Browser**، آدرس را در کادر **URL** بگذارید، **Width** را `800` و **Height** را `300`.

هر اندازه‌ای کار می‌کند؛ کادر بزرگ‌تر یعنی تصویر واضح‌تر.

## تنظیم‌ها

| | پیش‌فرض | |
| --- | --- | --- |
| `duration` | `5000` | مدت نمایش هر نفر به میلی‌ثانیه |
| `fade` | `380` | مدت انیمیشن به میلی‌ثانیه |
| `anim` | بسته به تم | `blur` · `fade` · `slide` · `wipe` · `none` |
| `glass` | بسته به تم | شفافیت، از `0` تا `0.9` |
| `accent` | `c2333a` | رنگ باریکه‌ی تم نواری، یا `none` |
| `scale` | خودکار | بزرگ‌نمایی دستی |
| `order` | `random` | با `list` به‌ترتیب اصلی |

## داده‌ها

فهرست از [یادمان جاویدنامان ایران‌اینترنشنال](https://javidnaman.iranintl.com/memorial) گرفته شده و در [`data.json`](data.json) است. هر نفر یک خط:

```json
{"id":"...","name":"نام کامل","age":28,"place":"تهران","date":"۱۹ دی ۱۴۰۴","photo":true}
```

هر فیلدی که `null` باشد، آن خط از کارت حذف می‌شود.

## مشارکت

اگر نامی جا افتاده یا اطلاعاتی اشتباه است، Issue باز کنید یا Pull Request بفرستید. هر نفر در `data.json` یک خط جداست تا ویرایش ساده باشد. برای عکس، فایل را با نام `<id>.jpg` در `images/` بگذارید و `photo` را `true` کنید.
