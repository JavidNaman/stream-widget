# ویجت یادمان جاویدنامان

یک ویجت شیشه‌ای برای OBS، با الهام از Liquid Glass اپل، که نام و عکس و سن و شهر و تاریخ **۳۱۷۵ جاویدنام** را یکی‌یکی و با انتقال نرم گوشه‌ی استریم نشان می‌دهد تا یادشان زنده بماند.

فهرست از [یادمان جاویدنامان ایران‌اینترنشنال](https://javidnaman.iranintl.com/memorial) گرفته شده است.

---

## راه‌اندازی در OBS

۱. در **Sources** روی **+** بزنید و **Browser** را انتخاب کنید.

۲. در قسمت **URL** این آدرس را بگذارید:

```
https://JavidNaman.github.io/stream-widget/
```

۳. ابعاد را دقیقاً این‌طور تنظیم کنید:

| تنظیم | مقدار |
| --- | --- |
| **Width** | `430` |
| **Height** | `130` |

۴. تیک **Shutdown source when not visible** را بزنید.

۵. **OK** را بزنید و ویجت را هرجای تصویر که خواستید بگذارید.

> ویجت به **گوشه‌ی بالا-راستِ** کادر Browser Source می‌چسبد و پس‌زمینه‌اش شفاف است.

## تنظیمات دلخواه

با افزودن پارامتر به انتهای URL می‌توانید رفتار ویجت را عوض کنید:

| پارامتر | پیش‌فرض | توضیح |
| --- | --- | --- |
| `duration` | `6000` | مدت نمایش هر نفر به میلی‌ثانیه |
| `fade` | `620` | مدت انتقال بین دو نفر به میلی‌ثانیه |
| `scale` | `1` | بزرگ‌نمایی ویجت (`0.4` تا `4`) |
| `glass` | `0.62` | غلظت شیشه (`0.25` تا `0.95`) |
| `order` | `random` | با `list` فهرست به‌ترتیب اصلی نمایش داده می‌شود |

مثال — نمایش ۱۰ ثانیه‌ای، ۲۵٪ بزرگ‌تر و شیشه‌ی شفاف‌تر:

```
https://JavidNaman.github.io/stream-widget/?duration=10000&scale=1.25&glass=0.5
```

**`glass` را کِی کم کنیم؟** پیش‌فرض `0.62` طوری تنظیم شده که حتی روی یک صحنه‌ی کاملاً سفید هم متن خوانا بماند. اگر صحنه‌ی شما همیشه تاریک است، `0.45` تا `0.5` شیشه را شفاف‌تر می‌کند و تصویر پشتش بیشتر دیده می‌شود.

اگر `scale` را عوض کردید، عرض و ارتفاع Browser Source را هم به همان نسبت زیاد کنید.

## چرا این‌طور ساخته شده

چند تصمیم که مخصوص OBS گرفته شده و شاید غیرمنتظره باشند:

**`backdrop-filter` استفاده نشده.** Browser Source صفحه را جدا از صحنه رندر می‌کند و پشت صفحه هیچ چیزی نیست، پس `backdrop-filter: blur()` هیچ تصویری برای محو کردن ندارد — فقط GPU مصرف می‌کند. به‌جایش کل جلوه‌ی شیشه **کشیده شده**: بدنه‌ی نیمه‌شفاف، لبه‌ی نورگرفته و درخشش سطحی، همه با gradient. شفافیت (alpha) کار می‌کند چون OBS خودِ صفحه را روی ویدیو کامپوزیت می‌کند؛ فقط محو کردنِ پشت‌زمینه کار نمی‌کند.

**فقط `opacity` و `transform` انیمیت می‌شوند.** این دو روی GPU کامپوزیت می‌شوند و باعث repaint نمی‌شوند. عمداً از انیمیت کردن `filter: blur` پرهیز شده چون روی سیستمی که هم‌زمان دارد استریم می‌کند، فریم می‌اندازد.

**بین دو انتقال، هیچ انیمیشنی اجرا نمی‌شود.** درخشش سطحی به‌جای اینکه دائم لوپ بزند، فقط یک‌بار موقع عوض شدن هر نفر رد می‌شود. یعنی ویجت بیشتر عمرش کاملاً بی‌کار است.

**عکس نفر بعدی از قبل decode می‌شود**، پس انتقال هیچ‌وقت منتظر شبکه یا دیکودر نمی‌ماند.

**وقتی صحنه فعال نیست ویجت متوقف می‌شود**، تا در پس‌زمینه فهرست را بی‌خود جلو نبرد.

**فونت داخل ریپو است**، پس اگر OBS به CDN گوگل دسترسی نداشت، ویجت باز هم درست نمایش داده می‌شود.

**اندازه‌ی کارت ثابت است** (۴۱۰×۱۱۶). عرضش از روی خود داده انتخاب شده: پهن‌ترین ۹۹٪ رکوردها در ۳۹۲ پیکسل جا می‌شوند. یعنی ویجت بین افراد هیچ‌وقت جابه‌جا یا کم و زیاد نمی‌شود.

تنظیمات سیستمی **Reduce Transparency**، **Increase Contrast** و **Reduce Motion** هم رعایت می‌شوند.

## ساختار پروژه

```
index.html            ویجت — یک فایل، بدون build و بدون وابستگی خارجی
data.json             فهرست ۳۱۷۵ نفره، هر رکورد در یک خط
images/               عکس هر نفر (۲۵۶px) + عکس پیش‌فرض برای بدون‌عکس‌ها
assets/               فونت وزیرمتن
scripts/sync.mjs      اسکریپت به‌روزرسانی فهرست از منبع
```

### ساختار هر رکورد در `data.json`

```json
{"id":"...","name":"نام کامل","age":28,"place":"تهران","date":"۱۹ دی ۱۴۰۴","photo":true}
```

| فیلد | توضیح |
| --- | --- |
| `id` | شناسه‌ی همان فرد در منبع، و نام فایل عکسش |
| `name` | نام کامل |
| `age` | سن، یا `null` |
| `place` | شهر یا محل، یا `null` |
| `date` | تاریخ شمسی، یا `null` |
| `photo` | اگر `false` باشد عکس پیش‌فرض نشان داده می‌شود |

هر فیلدی که `null` باشد، آن خط از کارت حذف می‌شود و بقیه‌ی کارت به‌هم نمی‌ریزد.

از این ۳۱۷۵ نفر: ۲۹۶۰ نفر عکس دارند، ۲۵۰۵ نفر سن، ۳۱۵۳ نفر محل و ۲۹۱۴ نفر تاریخ.

### دیدن ویجت روی سیستم خودتان

```bash
python -m http.server 4173
```

بعد `http://localhost:4173` را باز کنید. باز کردن مستقیم `index.html` از روی دیسک کار نمی‌کند، چون ویجت `data.json` را با `fetch` می‌خواند و مرورگر روی `file://` جلویش را می‌گیرد.

## به‌روزرسانی فهرست

فهرست منبع هنوز در حال تکمیل است. برای گرفتن نفرات جدید:

```bash
node scripts/sync.mjs
```

اسکریپت کل فهرست و جزئیات را دوباره می‌گیرد، فقط عکس‌های جدید را دانلود می‌کند، `data.json` را بازمی‌سازد و عکس‌های بی‌صاحب را پاک می‌کند. به Node.js نسخه‌ی ۱۸ یا بالاتر نیاز دارد و هیچ پکیجی نمی‌خواهد.

منبع، فهرست را از طریق Server Action‌های Next.js می‌دهد نه یک API عمومی. شناسه‌ی این اکشن‌ها با هر بار دیپلوی شدن سایت عوض می‌شود؛ اگر اسکریپت خطای `no payload line` داد، طرز پیدا کردن شناسه‌های جدید بالای [`scripts/sync.mjs`](scripts/sync.mjs) توضیح داده شده است.
